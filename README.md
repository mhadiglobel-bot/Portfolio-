# Muhammad Hadi — Portfolio

A responsive, motion-led portfolio built with Next.js, TypeScript, and a custom Three.js scene.

## Stack

- Next.js App Router
- React + TypeScript
- Three.js for the interactive hero sculpture
- Pointer-driven 3D parallax and lightweight scene animation
- Native IntersectionObserver for scroll reveals and progress
- Responsive CSS with reduced-motion support

## Local development

\`\`\`bash
npm install
npm run dev
\`\`\`

## Validation

\`\`\`bash
npm run typecheck
npm run build
\`\`\`
