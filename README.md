# Muhammad Hadi — Portfolio

A responsive, motion-led portfolio built with Next.js and TypeScript.

## Experience

- Matte black visual system with neon pink and violet accents.
- Editorial typography and a layered CSS 3D hero scene.
- Pointer-responsive depth, scroll progress and intersection-based reveals.
- Project archive with verified public links only.
- Original Hadi portrait used in the About section.
- Responsive navigation and reduced-motion support.

## Performance approach

- No Three.js, WebGL renderer, animation framework or smooth-scroll dependency.
- No remote font imports or external hero images.
- Motion uses CSS transforms and opacity; scroll reveals use native IntersectionObserver.
- The page remains fully visible if JavaScript or the reveal observer is unavailable.
- Reduced-motion preferences disable decorative motion.
