# Muhammad Hadi — Portfolio

A cinematic, single-page portfolio built with Next.js, TypeScript, custom WebGL ray-marched artwork, and scroll-aware motion.

## Stack

- Next.js App Router
- React + TypeScript
- Custom WebGL shader for the orbital 3D scene (no Blender export or third-party model required)
- Native IntersectionObserver and requestAnimationFrame for scroll reveals and progress
- Responsive CSS with reduced-motion support

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run build
```
